# Шаринг чека и экспорт в Excel (CSV)

Дата: 2026-06-11. Статус: одобрено пользователем в чате.

## Цель

Две быстрые фичи удобства из направления «Удобство и скорость»
(статусы сделки — отдельный следующий заход):

1. Отправка чека-картинки в мессенджер одним тапом.
2. Выгрузка склада и продаж в файл, открывающийся в Excel.

## 1. Шаринг чека

- Решение пользователя: отправлять **только картинку** (без текста-подписи).
- Кнопка «📤 ПОДЕЛИТЬСЯ ЧЕКОМ» под «💾 СОХРАНИТЬ ЧЕК» в чеке калькулятора;
  кнопка «📤» (с тултипом «Поделиться чеком») в действиях карточки машины.
- Механизм: PNG из `drawReceiptPNG` → `Blob` (синхронная конверсия через
  `atob`, чтобы не потерять user gesture) → `navigator.share({files})`.
- Фолбэк: если `navigator.canShare({files})` недоступен (десктопы) —
  обычное скачивание PNG (`downloadPNG`), как сейчас. Отмена шаринга
  пользователем (AbortError) — не ошибка, ничего не делаем.
- Код: хелперы в `js/receipt.js` (общая генерация PNG вынесена,
  чтобы не дублировать между «сохранить» и «поделиться»).

## 2. Экспорт в CSV

- Решение пользователя: **и сводка, и детализация** — в одном файле
  (две секции), один тап — одно скачивание (надёжно на iPhone).
- Кнопка «📊 EXCEL» в ряду «ЭКСПОРТ БАЗЫ / ИМПОРТ БАЗЫ».
- Формат: CSV, разделитель `;`, UTF-8 с BOM (Excel-ru сразу читает
  кириллицу), десятичная запятая в числах. Имя файла
  `АвтоСклад_<дата>.csv`.
- Секция «СВОДКА» — строка на машину: Название, Дата добавления, Статус,
  Себестоимость ₽, Дата продажи, Цена продажи ₽, Прибыль ₽, Наценка %,
  Маржа %, Дней на складе (для проданных — дней до продажи).
- Секция «ДЕТАЛИЗАЦИЯ» — строка на позицию: Машина, Статус, Категория,
  Валюта, Сумма, Курс ₽, Сумма ₽.
- Экранирование CSV: значения с `;`, `"` или переводом строки — в кавычках
  с удвоением кавычек (защита от формул/инъекций в названиях машин).
- Пустой склад → alert, файл не создаётся.
- Код: новый модуль `js/export.js`; подключение в `index.html`;
  `sw.js`: файл в список кэша, версия CACHE → v8.

## Вне объёма

Статусы сделки (куплено → в пути → таможня → склад → продано) — отдельный
заход со своим дизайном: меняет модель данных и UI карточки.

## Проверка

- Браузер (Playwright): экспорт скачивает файл, содержимое обеих секций
  соответствует данным склада; кнопки шаринга не падают на десктопе
  (срабатывает фолбэк-скачивание); карточка и чек рендерятся без ошибок.
- Ревью-workflow по диффу с адверсариальной верификацией находок.
