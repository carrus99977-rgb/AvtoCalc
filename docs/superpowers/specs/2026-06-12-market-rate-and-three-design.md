# Рыночный курс «₿ РЫНОК» + три удобства

Дата: 2026-06-12. Статус: одобрено пользователем в чате
(выбор: «только кнопка РЫНОК», без надбавки; + все три мелочи).

## 1. Кнопка «₿ РЫНОК» (js/cbr.js)

Запрос: курс ЦБ ниже реального обменного — нужен рыночный курс.
Исследование (проверено живьём, CORS открыт у обоих):
- CoinGecko `simple/price?ids=tether&vs_currencies=rub` → USDT/₽ —
  фактический «обменный» уровень (сегодня 72.28 против ЦБ 71.91).
- open.er-api.com `latest/USD` → форекс USD/₽ (запасной) и кросс EUR/USD.

Механика `fetchMarket()`:
- USD: CoinGecko USDT/₽; если недоступен — er-api USD/₽ (форекс).
- EUR: USD_рынок × (EUR/USD кросс из er-api). Если er-api недоступен,
  а CoinGecko жив — обновляется только USD, в подписи «EUR недоступен».
- Оба недоступны → понятная ошибка (как у ЦБ).
- Таймауты AbortSignal.timeout(10s); общий guard S.cbrBusy с кнопкой ЦБ.
- Дата (S.cbrDate) очищается: рыночный курс только «сейчас», истории нет.
- Подпись: «✓ Рынок на 14:32 · USDT 72.28» (+пометка источника/фолбэка).
- UI: кнопка «₿ РЫНОК» в cbr-row (оранжевый стиль #f7931a), ряд flex-wrap.

## 2. Добавить расход к машине (js/warehouse.js)

Боль: в ПРАВКЕ можно менять суммы, но нельзя добавить позицию
(ремонт/мойка/реклама после покупки) — себестоимость занижается.
- В режиме ПРАВКА под списком позиций кнопка «+ ДОБАВИТЬ РАСХОД»:
  добавляет в S.editCarEntries черновик-позицию с флагом `_new`.
- Карточка новой позиции: select категории (CATS), сумма, чипы валюты
  (RUB + активные), курс для не-RUB (по умолчанию из S.rates), кнопка ✕
  убрать строку до сохранения.
- saveCarEdit: существующая валидация (amount>0, rate>0 для не-RUB)
  распространяется на новые; label/icon берутся из выбранной категории;
  флаг _new не сохраняется в данные машины.

## 3. Заметка/VIN к машине (core + warehouse)

- Поле `car.note` (строка ≤500 симв.). normalizeCar сохраняет/обрезает.
- ПРАВКА: textarea «Заметка (VIN, комплектация, контакты)».
- Раскрытая карточка: блок заметки (esc, pre-wrap), если непустая.
- Поиск склада ищет и по заметке (whMatch).
- addToWH создаёт note:"".

## 4. Обратный калькулятор (js/calc.js, блок прибыли)

- В блоке «Расчёт прибыли» строка: «🎯 Наценка X % → цена N ₽».
  Поле X (S.targetMarkup, в draft), цена = себестоимость×(1+X/100),
  показывается в ₽ и в валюте продажи (по курсу из S.rates).
- Кнопка «→ В ПРОДАЖУ»: подставляет вычисленную цену в поле продажи
  (в выбранной валюте, округление до целых).
- Live-пересчёт при вводе X без полного render (partial, как rProfit).
