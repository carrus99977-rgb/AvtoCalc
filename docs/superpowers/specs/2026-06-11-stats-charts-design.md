# Интерактивные графики статистики

Дата: 2026-06-11. Статус: одобрено пользователем в чате.

Запрос: «прибыль по месяцам странно показывается» (одна полоса во весь
экран при единственном месяце) + хочется красивые интерактивные
гистограммы с палитрой и разбивкой «расходы на что / за что прибыль».
Выбраны все три графика.

## Технология

Собственный модуль `js/charts.js`, inline-SVG без библиотек: офлайн,
чёткость на retina, цвета и темы через текущие CSS-переменные/палитру,
тач-интерактив через inline onclick (как весь остальной код).
Состояние выбора: `S.chartMonth` (индекс), `S.chartCat` (ключ) — не
персистится. Частичная перерисовка контейнера `#charts-wrap` (rCharts),
чтобы тапы не дёргали всю страницу.

## 1. Гистограмма «Прибыль по месяцам»

- Последние 12 месяцев всегда (пустые видны) — одинокий месяц больше
  не растягивается во весь блок.
- Вертикальные столбики от нулевой линии: прибыль зелёная вверх,
  убыток красный вниз. Подписи месяцев (рус. сокращения), при смене
  года — метка года.
- Тап по столбику → панель под графиком: «Июнь 2026: +10 350 500 ₽ ·
  4 машины». По умолчанию выбран последний непустой месяц.
  Выбранный столбик подсвечен золотой обводкой.

## 2. Пончик «Расходы по категориям»

- По всем проданным машинам, суммы позиций в ₽ (entryRub по курсам машины).
- Палитра: стоимость авто #5B8FF9, логистика #5AD8A6, таможня #F6BD16,
  утильсбор #E8684A, ЭПТС #9270CA, прочее #6DC8EC.
- В центре — итог расходов (компактный формат «67,4 млн ₽»).
- Легенда: цвет, иконка+название, сумма, %. Тап по сектору или строке
  легенды — подсветка обоих.

## 3. «Прибыль по машинам»

- Горизонтальные полосы по проданным, сортировка по прибыли,
  топ-8 + строка «и ещё N машин». Прибыльные зелёные, убыточные красные,
  имя машины + сумма. Без доп. интерактива.

## Интеграция

- `js/stats.js`: карточки-итоги остаются; блок «Прибыль по месяцам»
  заменяется тремя графиками. Секция по-прежнему появляется после
  первой продажи.
- Версия релиза → 17: `const V` в sw.js, `?v=17` в index.html,
  `js/charts.js` в список скриптов и FILES.

## Проверка

Сид данных, похожих на реальные (4 продажи в одном месяце, расходы по
всем категориям, + сценарий с убыточной машиной и продажами в разных
месяцах): скриншоты тёмной/светлой темы, тапы по столбику/сектору,
пустое состояние (нет продаж). Ревью-workflow по диффу.
