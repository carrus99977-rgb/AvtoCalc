# 🚗 АвтоКальк

PWA-калькулятор себестоимости импортных автомобилей: расходы по категориям
в разных валютах с фиксацией курса за каждой позицией, склад, учёт продаж,
прибыль/наценка/маржа, чеки-картинки, статистика и облачная синхронизация.

Работает офлайн, ставится на домашний экран телефона как приложение.

## Возможности

- **Калькулятор**: цена авто, логистика, таможня, утильсбор, ЭПТС/СБКТС, прочее
- **Валюты**: ₽ € $ ¥ (юань) ₩ (вона) JP¥ (иена) — набор настраивается чипами
- **Курс ЦБ РФ** одной кнопкой: на сегодня или на выбранную дату
  (для оплат задним числом), выходные откатываются к рабочему дню
- **Курс фиксируется за позицией** в момент добавления; редактируется
  по факту оплаты (по одной позиции или массово)
- **Склад**: поиск, сортировка, «заморожено ₽», средний возраст стока
- **Продажи**: прибыль, наценка, маржа, статистика по месяцам
- **Чеки** в PNG для отправки клиенту/партнёру
- **Бэкап** в JSON (экспорт/импорт) и облачная синхронизация (Supabase)
- Тёмная и светлая темы

## Структура

```
index.html        — каркас страницы
styles.css        — все стили (темы через CSS-переменные)
js/core.js        — состояние, валюты, персистентность, хелперы денег
js/cbr.js         — загрузка курсов ЦБ РФ
js/cloud.js       — облачная синхронизация (Supabase) с офлайн-очередью
js/calc.js        — калькулятор, позиции, расчёт прибыли
js/warehouse.js   — склад, продажи, редактирование, поиск, бэкап
js/stats.js       — статистика по проданным
js/receipt.js     — чеки (HTML и PNG через canvas)
js/main.js        — render() и запуск
sw.js             — service worker (офлайн-кэш, версия в CACHE)
```

Сборки нет — обычные скрипты, общее состояние в глобальном объекте `S`.
При изменении набора файлов обновите список `FILES` и версию `CACHE` в `sw.js`.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Через `file://` service worker не работает — нужен любой http-сервер.

## Публикация

Подойдёт любой статический хостинг с HTTPS (GitHub Pages, Netlify, Vercel):
залить файлы как есть. HTTPS обязателен для service worker и установки PWA.

## Облако и безопасность

Синхронизация — через Supabase (вход по почте/паролю). Обязательно настройте
политики Row Level Security, иначе пользователи могут видеть чужие данные:
см. [SUPABASE_SETUP.md](SUPABASE_SETUP.md).

## Данные

Локально всё хранится в `localStorage` (черновик — `autoCalc_draft`,
склад — `autoCalc_wh`). Регулярно делайте «💾 ЭКСПОРТ БАЗЫ»: браузер может
очистить localStorage у долго неиспользуемых сайтов.
